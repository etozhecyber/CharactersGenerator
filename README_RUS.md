# Запуск генератора персонажей локально

Этот проект использует современные веб-технологии: React, TypeScript и сборщик Vite.
Поскольку код написан на TypeScript (файлы `.tsx` и `.ts`), его нельзя просто открыть в браузере как обычный HTML-файл. Для работы требуется запустить локальный сервер разработчика (Vite), который "на лету" преобразует код в понятный браузеру формат.

## Предварительные требования

У вас должен быть установлен **Node.js** (скачать можно с [официального сайта](https://nodejs.org/)). 

## Инструкция по запуску

1. **Установите зависимости**
   Откройте терминал (командную строку) в папке с проектом и выполните команду:
   ```bash
   npm install
   ```
   *Это скачает все необходимые библиотеки (React, Vite и другие) в папку `node_modules`.*

2. **Настройте API ключ Gemini**
   Создайте файл с названием `.env.local` в корне проекта (рядом с `package.json`).
   Откройте его в любом текстовом редакторе и добавьте ваш ключ:
   ```env
   GEMINI_API_KEY=ваш_ключ_от_gemini
   ```

3. **Запустите локальный HTTP-сервер**
   Выполните в терминале команду:
   ```bash
   npm run dev
   ```
   После запуска терминал покажет ссылку (обычно `http://localhost:3000` или `http://localhost:5173`). Откройте эту ссылку в браузере.

## Запуск с помощью простого HTTP-сервера (без Node.js в будущем)

Если вы хотите получить "чистый" набор HTML/JS/CSS файлов, которые можно запускать любым простейшим сервером (например, `python -m http.server`), вам нужно "собрать" проект:

1. Выполните команду:
   ```bash
   npm run build
   ```
2. Появится папка `dist`. Внутри неё лежат готовые статические файлы.
3. Теперь вы можете запустить любой простой сервер именно в папке `dist`. Например:
   ```bash
   cd dist
   python -m http.server 8000
   ```
   И открыть `http://localhost:8000`.
